Port of
LiquidSketch [iOS](https://apps.apple.com/us/app/liquidsketch/id544717096)
[Android](https://play.google.com/store/apps/details?id=net.tobiasneukom.liquidsketch)
fluid simulation to Rust with an egui interface for experimentation.



https://github.com/user-attachments/assets/7df9a042-7d4d-4377-807a-6d19eb4b9519



Features

- FLIP (fluid implicit particle) method
- [Conjugate gradient](https://en.wikipedia.org/wiki/Conjugate_gradient_method)
  (with preconditioner) pressure solver
- Grid boundary conditions
- Liquid surface reconstruction using OpenGL
- Color advection using OpenGL
- Forces: Gravity, arbitrary radial force, Uniform force
